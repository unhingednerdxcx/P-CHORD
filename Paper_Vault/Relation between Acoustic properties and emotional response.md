# Abstract
Before we begin, I would like to make it clear that this study is not intended to be used as a highly accurate research. This study is only done because I wanted to explore the field and find the relation between sound and our emotional response.

This study will investigate the relation between acoustic properties and emotional response.
This study only considers in the following acoustic properties 

- **Frequency**
- **Amplitude**
- **Intensity**
- **Duration of sound**
- **Brightness**
- **Roughness**
- **Sharpness**
- **Attack time**
- **Decay time**

As for the emotions, I want to use **Russell's Circumplex Model of Affect** which measures emotions in a grid where the horizontal axis represents **Valence**, and the vertical axis represents **Arousal**. 

The plan for this study is:
- Record result in a SQL database
- Then try to find patterns in those results with ML (machine learning)
- Map those patterns into my own hierarchy of pattern:
	- Cellular (newly found pattern)
	- Fibrous (seems to appear more repeatedly)
	- Visceral (seems to play more of a major role)
	- Systemic (might be a core to understanding psychoacoustics)
- Display those patterns in a more readable format
- Try and reason from those patterns

To see my reasoning, check the Diary folder.
